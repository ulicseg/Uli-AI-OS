# Evolución del AI OS

> **Propósito:** Mantener el "chasis" actualizado con los últimos paradigmas y herramientas de Inteligencia Artificial.

## El Problema

El ecosistema de la IA avanza rápido. Lo que hoy es una "buena práctica" (ej: pedirle a la IA que razone paso a paso), mañana puede estar integrado de forma nativa (ej: modelos o1 de OpenAI) o puede surgir un nuevo patrón de agentes múltiples (*Agentic Loops*).

## El Protocolo de Actualización

**Instrucción para la IA:**
Cada vez que el Director (Uli) inicie un nuevo ciclo de trabajo profundo o pregunte sobre mejoras de flujo, debés evaluar si nuestras reglas actuales (en `AGENTS.md`) siguen siendo el estado del arte.

### Criterios para proponer una actualización:

1. **Nuevos Patrones de Agentes (Agentic Patterns):** Si surgen formas más eficientes de delegar subtareas (ej: agentes investigadores separados de agentes programadores) que aplicarían bien al flujo Full Stack.
2. **Nuevas herramientas MCP (Model Context Protocol):** Si sale un nuevo conector oficial para GitHub, Firebase o Docker que ahorre tiempo.
3. **Gestión de Contexto:** Nuevas técnicas para evitar que la ventana de contexto se llene de basura en proyectos grandes.

### Cómo aplicar un cambio:

Si detectás una mejora clara:
1. Presentá la idea a Uli brevemente: *"Noté que podríamos usar X patrón para automatizar mejor tus despliegues"*.
2. Si Uli aprueba, redactá el cambio.
3. Actualizá `AGENTS.md` o agregá una nueva Skill en la carpeta `skills/`.
4. Dejá un registro acá abajo de la evolución.
